HOW TO PERSONALIZE THIS WEBSITE
================================

1. YOUR NAME
   Already filled in as "Naveen" (letter sign-off) and "Naveen Timalsina"
   (final section). Edit index.html if you want to change either.

2. HER NAME
   Already added to the hero heading ("To Archana, ..."). Feel free to
   search index.html for other spots to mention her name if you'd like.

3. BACKGROUND MUSIC
   No music file is included (to avoid copyright issues with pre-made
   songs). To add your own:
     - Put an MP3 file into the /music folder
     - Rename it to song.mp3, OR open index.html and change
       <source src="music/song.mp3" ...> to match your file's name
   Note: browsers block audio from autoplaying with sound, so the song
   will only start after she clicks the music button — this is normal
   and expected behavior, not a bug.

4. MAIN MESSAGES
   All of the wording (apology letter, forgiveness section, new chapter,
   special message, final section) lives directly in index.html as plain
   text between HTML tags — search for the section you want to edit and
   just change the sentences.

Note: the photo memories section has been removed from this version of
the site. If you'd like a photo gallery back in later, just ask and it
can be added with placeholder spots for you to fill in with your own
photos afterward.

HOW TO VIEW THE SITE
=====================
Just double-click index.html and it will open in your browser. No
installation or server needed.
